一、项目概览

1.1 项目定位

本项目是面向 3DGS（3D Gaussian Splatting）轻量化研究的本地 Web 分析平台，定位为软著申报与研究辅助工具。系统采用前后端分离架构，覆盖从模型导入、属性解析、统计分析、三维预览、属性可视化、剪枝压缩、压缩前后对比、实验记录到报告导出的完整研究闭环。

代码仓库：3dgs-compression-platform。

1.2 核心能力地图

mindmap root((3DGS 压缩平台)) 模型管理 PLY 上传导入 服务器目录零拷贝注册 模型 / 实验删除 属性解析 PLY Header 解析 高斯属性统计 属性直方图 三维预览 自研高斯点云查看器 SuperSplat 查看器 WASD 漫游 + 同步对比相机 压缩算法 Opacity 剪枝 Scale 剪枝 Importance Top-K XGaussian 集成 质量评估 体素 PSNR/SSIM/LPIPS 渲染图像指标 XGaussian 渲染器适配 批量实验 结构化实验计划 自定义方法组合 命名预设持久化 报告导出 Markdown / HTML Excel 工作簿 批量方法均值可视化 系统支撑 资源监控 启动恢复 数据清理

  1. 分层严格：API 路由薄、服务层厚、算法独立，后续替换 XGaussian 版本时不影响上层
  2. 仓储模式：统一 base.py 分页方法，Phase 14 性能优化一次覆盖 5 个 API
  3. 渲染器抽象：renderers/base.py 为后续接入其他渲染器留出扩展点

9.2 流程经验

  1. 短分支频繁合并：14 天内 16 条特性分支全部合并，无长期挂起分支
  2. MVP 优先：Phase 4 一天内打通"压缩→对比→报告"闭环，再逐步增强
  3. 测试共置：前端测试与源码同目录，降低维护成本
