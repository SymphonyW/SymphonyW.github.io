那些不知道是谁启动的进程，终于能看明白了：OpenEnd

从端口冲突到后台进程、项目归属和网络流量，用真实界面介绍 OpenEnd 如何帮 Windows 用户看清本机正在运行什么。

“5173 端口又被占用了。”

做本地项目时，这句话很熟悉。换个端口当然能继续，但我更想知道：是谁还在用它？任务管理器里一排 node.exe、python.exe、Code.exe，名字认识，却不知道它们属于哪个项目，哪些还在工作，哪些早该关了。

尤其是同时开着几个项目，再让 AI 编程工具跑些任务，后台进程很快就变成了一笔糊涂账。于是我做了 OpenEnd，一个面向 Windows 用户的本地进程、端口和系统资源管理工具。

电脑变卡，先找出忙碌的进程

我通常先看性能页。CPU、内存、GPU、显存和网络可以分别查看曲线，下面还有进程数、线程数、端口数和运行时间。电脑突然变卡时，先看看哪项资源吃紧，再去找具体进程，比凭感觉猜更直接。

按占用排序，按来源搜索

进程页把名称、PID（进程编号）、CPU、内存、端口和所属应用放在一行里，还能查看程序路径和启动命令。按内存或 CPU 排序，占用靠前的项很快就能找到。

搜索也不必只盯着程序文件名。比如输入 Code，截图里既能找到 Visual Studio Code，也能看到归属 Codex 的进程。有些进程虽然显示为 ChatGPT.exe，所属应用却能提供更多线索。AI 工具启动了多个后台任务时，这些信息就很有用。

“未识别归属”或“不可用”不代表进程异常，只是当前信息不足。是否需要结束，还是要结合它正在做的事情判断。

端口被占用，找到对应服务

端口冲突则从端口页开始。输入端口号，或者按进程名、TCP / UDP 协议、连接状态筛选，就能缩小范围。同一个应用开了哪些连接，也可以展开查看。

查端口，再确认是否结束

以我自己的博客预览为例，搜索 1313，能找到属于 myBlog 的 hugo.exe。同一个 PID 可能出现在不同连接状态的行里，并不意味着启动了好几个服务。

点开详情，路径、启动命令和工作目录能帮助确认它是不是忘关的预览。确定不需要了，再点“结束占用”，弹窗会列出创建时间、PID、协议和路径。这里结束的是整个进程，它负责的其他服务也会停止。

按应用和项目分组查看

当列表太长时，可以切到“应用与项目”，先看分组的内存、进程数和端口，再展开具体成员，或跳转到对应进程。截图里两个同名 Codex 分组的程序路径不同：名字相同，来源未必相同。

同时跑前端、后端和博客预览时，这样看更容易分清归属。自动判断拿不准的，还能在详情里手动指定项目目录，并选择记住工作目录规则。

谁在使用网络

另一个常见疑问是：网络一直忙，到底是谁在传东西？

这里按应用和项目汇总累计下载、上传、合计流量和当前速度，也能展开看进程。截图中 OpenSSH 以下载为主，远程控制工具以上传为主。安装依赖、传文件或使用远程工具时，不仅能看谁用了流量，还能分清传输方向。

统计时段和流量范围

右上角标出了统计时间。这是本次运行期间的累计值，不能补回采集前的流量，退出后会清空。默认范围包含局域网，本机 localhost 通信可以单独查看；性能页的网络曲线则展示最近 60 秒的收发速度。

代理或 VPN 会转发其他应用的数据，所以不能把各应用的数字直接相加，当成宽带账单。

开发结束后的收尾

开发结束后，我会再看清理页。它按规则列出开发相关候选项，供人检查和选择。截图里的 MySQL 命中了数据库规则，但如果项目还在用它，就应该保留。出现在这里，不等于已经闲置。

调整保护名单和清理规则

想减少误操作，可以到设置里添加受保护的进程名，默认也会保护部分关键 Windows 进程。清理规则能按进程名、命令关键字、端口和端口范围调整，中英文界面也在这里切换。

回看操作日志

通过 OpenEnd 执行的结束和清理操作会留下日志。后来发现某个服务停了，可以回来核对时间、进程、PID 和结果，看看是不是自己之前做过处理。

下载和日常使用

目前支持 Windows 10 / 11。从 GitHub Releases 下载安装后，启动时确认系统的管理员授权提示即可。安装包尚未代码签名，可能出现 SmartScreen 或“未知发布者”提示，请核对下载来源。

点击右上角关闭按钮会收进系统托盘，网络统计继续进行；点击托盘图标可恢复，右键选择“退出”才会真正结束并清空本次流量。再次启动快捷方式，也会唤起已有窗口。

反馈与开源项目

如果遇到问题，反馈页提供邮件入口和模板，方便整理复现步骤、相关进程、端口和截图。

我希望 OpenEnd 能减少那些查命令、猜进程、找后台服务的小打断。先看清楚机器正在做什么，再决定要不要动它。

项目已经在 GitHub 开源。欢迎下载试用，遇到问题或有功能建议，可以提交 Issue。
