从峡湾到极光：2015—2024 年北欧五国入境旅游可视分析

这个页面是《数据可视化》课程大作业的公开展示入口。原项目使用 Streamlit 实现多页面交互应用；博客上的版本导出为静态 HTML，保留 Plotly 图表的悬停、缩放、图例开关等交互，适合通过 GitHub Pages 直接访问。

打开完整静态展示页

发布方式

当前博客是 Hugo 静态站点，不能直接运行 Streamlit 的 Python 服务。因此这里采用“静态导出 + 博客嵌入”的方式：

方案 适合场景 结果
静态导出到 Hugo 希望随博客一起发布、长期稳定访问 本文嵌入的静态展示页
Streamlit Cloud / Render 部署 必须保留侧边栏筛选、多页面跳转和下载按钮 需要额外部署一个 Python Web 服务，再从博客链接过去

本静态页使用真实处理后数据生成，不包含模拟数据；其中年度总览默认展示 2024 年，客源市场结构默认展示覆盖五国更完整的 2023 年。
