From Fjords to Northern Lights: Nordic Inbound Tourism Visualization, 2015-2024

This page is the public entry point for my data visualization course project. The original project is a multi-page Streamlit app; the blog version is exported as static HTML while preserving Plotly interactions such as hover, zoom, and legend toggles.

Open the full static page

Publishing Approach

This blog is a Hugo static site, so it cannot run the Streamlit Python server directly. I use a static export and embed it in the blog:

Option Best for Result
Static export to Hugo Stable public access through the blog The embedded page above
Streamlit Cloud / Render deployment Keeping Streamlit sidebar filters, pages, and downloads A separate Python web service linked from the blog

The static page is generated from real processed data, not mock data. The annual overview defaults to 2024, while source-market charts default to 2023 because it has fuller five-country coverage.
