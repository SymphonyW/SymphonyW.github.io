Those Mystery Processes Finally Make Sense: OpenEnd

A practical look at OpenEnd for Windows: trace occupied ports, identify background processes, group apps and projects, and see where network traffic goes.

“Port 5173 is already in use.”

If you work on local projects, you have probably seen that message plenty of times. Changing the port gets you moving again, but I usually want to know what is still using it. Task Manager shows rows of node.exe, python.exe, and Code.exe. I recognize the names, but which project do they belong to? Which are still working, and which should have stopped hours ago?

Run several projects alongside an AI coding tool, and the background processes become difficult to track. That is why I made OpenEnd, a local process, port, and system resource manager for Windows.

Find Busy Processes When the Computer Feels Slow

I usually start with Performance. You can switch between CPU, memory, GPU, VRAM, and network charts, with process, thread, and port counts and system uptime below. When the computer feels slow, this helps me decide which resource to investigate before looking for a particular process.

Sort by Usage and Search by Origin

Processes puts the name, PID (the process’s identifying number), CPU, memory, ports, and owning application in one row. Executable paths and command lines provide more context. Sorting by memory or CPU brings the busiest entries to the top.

Search can find more than an executable name. Entering Code in the screenshot brings up Visual Studio Code as well as processes assigned to Codex. Some of those are named ChatGPT.exe, so the owning application adds a useful clue. This helps when an AI tool has several background tasks running.

Unidentified or Unavailable does not mean a process is faulty. It means there is not enough information to identify it. Whether to stop it still depends on what it is doing.

Find the Service Behind an Occupied Port

For a port conflict, start with Ports. Enter a port number or narrow the list by process name, TCP or UDP, and connection status. You can also expand an application to inspect its connections.

Search the Port Before Stopping Anything

My own blog preview is a useful example. Searching for 1313 finds hugo.exe, assigned to myBlog. The same PID can appear in rows with different connection states; that does not mean several copies of the service are running.

Open its details to check the path, command line, and working directory. If it is a preview you no longer need, choose End Occupancy. The confirmation shows the creation time, PID, protocol, and executable path. This stops the whole process, including anything else that process is serving.

Group by Application and Project

When a list becomes too long, switch to Apps & projects. Check a group’s memory, process count, and ports first, then expand its members or jump to its processes. The two Codex groups in this screenshot have different executable paths, a useful reminder that matching names do not necessarily mean matching origins.

This is easier to navigate when a frontend, backend, and blog preview are all running. If automatic ownership identification needs correcting, you can assign a project directory in the details and choose to remember the working-directory rule.

See Who Is Using the Network

Another familiar question: the network is busy, but what is actually transferring data?

Network groups cumulative downloads, uploads, total traffic, and current speeds by app and project. Expand a group to inspect its processes. In the screenshot, OpenSSH traffic is mostly downloads, while the remote-control tool is mostly uploads. When installing dependencies, transferring files, or working remotely, that shows both who used the network and in which direction.

Understand the Statistics Period and Scope

The statistics period is shown at the top right. Totals cover the current run, cannot recover traffic from before collection began, and reset when OpenEnd exits. The default scope includes LAN traffic; localhost communication can be viewed separately. The network chart in Performance shows download and upload speeds over the last 60 seconds.

A proxy or VPN can forward other applications’ data. Adding all application totals together does not turn them into an internet-provider billing figure.

Clean Up After a Development Session

At the end of a development session, I also check Cleanup. It uses rules to list development-related candidates for review and selection. The MySQL process in this screenshot matches the database rule, but it should stay running if a project still needs it. Being listed does not mean it is idle.

Adjust Protection and Cleanup Rules

Settings lets you add protected process names alongside built-in protections for certain critical Windows processes. You can adjust cleanup rules using process names, command keywords, ports, and port ranges. This is also where you switch between Chinese and English.

Review Operation Logs

Stop and cleanup operations performed through OpenEnd leave operation logs. If a service is missing later, check the time, process, PID, and result to see whether you stopped it earlier.

Download and Everyday Use

OpenEnd currently supports Windows 10 and 11. Download it from GitHub Releases, then approve the Windows administrator permission prompt on launch. The installer is unsigned, so SmartScreen or an “Unknown publisher” warning may appear. Check that the download came from the official release page.

Closing the window sends OpenEnd to the system tray, where network collection continues. Click the tray icon to restore it, or choose Exit from its context menu to quit and clear the session traffic totals. Launching the shortcut again also restores the existing window.

Feedback and the Open Source Project

If something goes wrong, Feedback provides an email entry point and a template for reproduction steps, relevant processes, ports, and screenshots.

My aim is to reduce the small interruptions spent looking up commands, guessing at processes, and tracking down background services. See what the machine is doing, then decide what needs to change.

OpenEnd is open source on GitHub. Downloads are available to try, and Issues are welcome for problems and suggestions.
